General purpose build with no platform restrictions

-- Build

Install the X64 version of 7z from https://www.7-zip.org/
Create the "release" dir at the root of the repository
create the "fonts" dir in the "scr" dir and obtain "DINEngschrift-Regular.ttf" and "kochi-gothic-subst.ttf"

Run make.bat

This screensaver aims to recreate the "OVKLToolSys" screen seen in PAYDAY 2 as a windows screensaver.
